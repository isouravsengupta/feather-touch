# Feather Touch

A typing trainer. Ten minutes a day, eyes on the screen, until your fingers know the keyboard.

World-average adult speed is about **40 WPM at ~95% accuracy without looking**. At 10 focused minutes a day that is usually **4–8 weeks**.

## Run it

```bash
npm install
npm run dev
```

The app opens at [http://localhost:5173](http://localhost:5173). Progress is saved in your browser (`localStorage`). Nothing is sent to a server.

## How to practice

1. Place left hand on `A S D F` and right hand on `J K L ;`. Index fingers rest on the F and J bumps.
2. Check **I will not look at the keyboard**.
3. Type the highlighted line. If you peek, restart the line.
4. Stay on a lesson until accuracy is at least 95%. Speed comes after that.

## Lessons

Week 1 home row → week 2 remaining letters → week 3 shift, punctuation, and numbers → week 4 Python lines and sentence fluency.
